# 正典の書式と記入例

`bible/`・`plot/`・`log/` の各ファイルに何を、どの形で書くかをまとめる。
`/start-novel` が正典を初期化するときと、`/write-chapter` が最初の章の記録を書くときに読む。
第 2 章以降は、既にある記録を見本にすればよい。

**記入例はすべて架空の作品のもので、正典ではない。** 例の固有名詞や設定を、新作の正典に持ち込まない。
例の作品：港町の古い時計店を継いだ主人公が、修理を頼まれた懐中時計から、町の古い失踪事件に近づいていく話。

## 共通の決まり

- 「確定」と書くのは、ユーザーが決めた事項か、本文に書いて点検を通った事項だけ。推測で埋めない。
- 決まっていないことは、空欄にせず `plot/open_questions.md` に書く。
- 確定した章や日付を、括弧で添える（例：「第3章で確定」「2026-11-20 ユーザー確認」）。あとで出所をたどれるようにするため。
- 数値（年齢、時刻、金額、年数）は、算用数字か漢数字かをファイルごとに揃える。年表と人物表は算用数字にする。
- 表の列は増やしてよいが、見出し行の名前は変えない。スキルとエージェントが見出しで探すため。

## bible/theme.md

| 見出し | 書くこと |
| :-- | :-- |
| 方向性 | ジャンル、読み味、想定読者 |
| 主題 | 作品が手放さない問いと、描き方の方針。点検エージェントが「主題との整合」で照合する |
| 物語の基本構造 | 誰が、何をきっかけに、何を目指し、どう変わるか。結末の方向 |
| 題名（仮題） | 仮題と、その題名が本文に課す制約 |

記入例：

```markdown
## 主題

- 「直すこと」と「元に戻すこと」は違う。壊れたものは、直しても前と同じにはならない。
- 失踪の当事者を、誰も悪人として裁かない。責任は描くが、断罪の台詞で片づけない。
```

## bible/characters.md

- 「呼称の統一」は、`A → B：呼び方（理由。確定した章）` の形で組み合わせごとに 1 行書く。地の文での呼び方（姓か名か）もここに書く。
- 人物は `### 氏名（よみがな）` の見出しで 1 人ずつ。箇条書きで、年齢（作中現在）、職業、性格、口調と一人称、物語での役割、まだ明かしていない秘密（明かす章）を書く。

記入例：

```markdown
## 呼称の統一（会話中の呼びかけ方）

- 灯 → 祖母：「おばあちゃん」。客の前では「店主」（第1章で確定）。
- 地の文では、灯は名で、刑事の北村は姓で書く（第1章で確定）。

### 早瀬 灯（はやせ あかり）

- 主人公。27歳。祖母の時計店を継いで2年目。
- 一人称は「わたし」。丁寧語が抜けると早口になる。
- 部品の摩耗から、持ち主の使い方を言い当てる。ただし人の気持ちには鈍い。
- 父が失踪したことを、第6章まで誰にも話さない。
```

## bible/world.md

- 確定した設定だけを書く。構想中のものは `plot/open_questions.md` へ。
- 現実の制度や業務（警察の手続き、医療、法律など）を描く部分は、確かめた資料の名前やリンクも書く。生成 AI の出力だけに頼らない。

記入例：

```markdown
## 主要モチーフ

### 止まった懐中時計（第1章で設置、第9章で意味が明かされる）

- 蓋の裏に、持ち主の頭文字ではない「K.S.」の刻印がある。
- 時計は 3 時 7 分で止まっている。この時刻は失踪当日の最終便の出港時刻と一致する（第9章で確定）。
```

## bible/timeline.md

- 「基準」に、作中現在の表し方を決めて書く（実在の西暦を使うか、「X年」のように抽象化するか）。
- 「作中の進行」は章を書き終えるたびに 1 行追記する。日時は曜日まで書く。

記入例：

```markdown
| 章 | 作中日時 | 確定した進行 |
| --: | :-- | :-- |
| 1 | X年6月第2週の火曜日、午後〜夜 | 灯が懐中時計の修理を引き受ける。依頼人は連絡先を書かずに帰る。 |
```

## plot/outline.md

- 「構成」の表は、章、目安字数、主な視点、役割。目安の合計を最後の行に書く。
- 「進捗」は章を書き終えるたび、本文を直すたびに更新する。字数を書くのはこの表だけ（ほかのファイルには書かない）。章題が仮のうちは備考に「仮」と書く。

記入例：

```markdown
| 章 | 目安 | 主な視点 | 役割 |
| --: | --: | :-- | :-- |
| 1 | 7,000字 | 灯 | 懐中時計の依頼。町の噂。 |
| 2 | 8,000字 | 灯／北村 | 依頼人の正体。失踪事件の記録。 |

| 章 | 状態 | 初稿字数 | 最終字数 | 目安比 | 備考 |
| --: | :-- | --: | --: | --: | :-- |
| 1 | 推敲済み | 5,880 | 7,120 | 102% |  |
```

## plot/foreshadowing.md

- 1 つの伏線に 1 行。「設置」「回収」は章番号、「進展」は章番号と短い説明。
- 「状態」は `未設置`・`設置済み`・`進展`・`回収済み` のどれか。回収済みの説明は 1 行に収め、詳細は `log/continuity.md` に書く。
- 回収章を決めずに伏線を張らない。

記入例：

```markdown
| # | 伏線 | 設置 | 進展 | 回収 | 状態 |
| --: | :-- | --: | :-- | --: | :-- |
| 1 | 懐中時計の「K.S.」の刻印 | 1 | 4（祖母が刻印の職人を知っている） | 9 | 進展 |
```

## plot/open_questions.md

- 「未確定」には、項目と、いつまでに決める必要があるか（どの章の執筆前か）を書く。
- 確定したら、該当する正典へ反映し、「確定した事項」に取り消し線つきで移す。

記入例：

```markdown
## 未確定

- 依頼人が灯の店を選んだ理由（第3章の執筆前に決める）

## 確定した事項

- ~~北村が失踪事件を担当していたか~~ → 担当ではなく、当時の新人として記録を清書した（2026-11-20 ユーザー確認、第2章）。
```

## log/continuity.md

各章の項は、見出し `## 第N章「章題」` に続けて、次の欄を書く。

| 欄 | 書くこと |
| :-- | :-- |
| 作中日時 | 曜日と時間帯まで |
| 視点 | 場面ごとの視点人物の並び |
| 要約 | 3〜5 行 |
| 確定した事実 | 固有名詞、数値、場所、持ち物、人物の来歴。本文の該当行を（行番号）で添えてよい |
| 人物の状態変化 | 誰が何を知ったか、関係がどう動いたか。「まだ知らないこと」も書く |
| 設置／回収した伏線 | `plot/foreshadowing.md` の番号と対応させる |
| 次章への申し送り | 未解決のまま持ち越した事項 |

本文を直したときは、該当する欄の記述を直し、修正の理由を短く括弧で添える（例：「（2026-11-22 修正。動作の順序を入れ替えた）」）。
理由の説明が長くなるときは、コミットのメッセージに書く。

記入例：

```markdown
## 第1章「止まった針」

**作中日時**：X年6月第2週の火曜日、午後〜夜

**視点**：灯→灯→北村→灯（四場面）

**要約**：
灯の店に、連絡先を書かない依頼人が懐中時計を持ち込む。時計は 3 時 7 分で止まっている。
夜、灯は蓋の裏の刻印に気づくが、祖母には言わない。

**確定した事実**：

- 時計店の名前は「早瀬時計店」。坂の途中、港から徒歩 10 分。
- 依頼人は 60 代の男性。代金を前払いし、「急がない」と言った。

**人物の状態変化**：

- 灯は刻印の存在を知ったが、意味は知らない。祖母は刻印をまだ見ていない。

**設置／回収した伏線**：#1 を設置。

**次章への申し送り**：

- 依頼人の名前は伝票に書かれていない。第2章で北村が来店した時点でも、灯は名前を知らない。
```
