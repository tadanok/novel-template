# 見本：軽快なユーモア・ミステリー

`.claude/rules/style-genre.md` の見本。`/start-novel` で新作のジャンルがこれに近いとき、写して作品に合わせて直す。
軽快なユーモア・ミステリーのジャンル部分のルールの見本。文体の土台（読みやすさ・会話・人物造形の一般則・表記の既定）は `style-base.md` にあるので、ここには書かない。

## ジャンルと基本トーン

- 読み心地は軽やかで親しみやすく、陰惨さに偏らない
- 緊張感のある状況でも、人物の反応や会話に小さな可笑しみを含める
- ユーモアはギャグの連発ではなく、人物の性格・認識のズレ・状況の皮肉から生む
- 登場人物を突き放して嘲笑せず、弱さや滑稽さにも温かい視線を向ける
- 犯罪や危機を扱う場合も、残虐描写・過度な恐怖演出・陰鬱な独白を必要以上に引き延ばさない
- 読者が「次に何が起きるのか」を気軽に追いかけられるテンポを優先する

## ジャンルの約束事

- 緊迫した局面では、短い返答、言いよどみ、見当違いな一言などで緩急をつける
- ボケ役とツッコミ役を固定しすぎず、場面ごとに反応のズレを活かす
- 冗談や皮肉は短く、物語の進行を妨げない範囲に留める
- 主人公は完璧な名探偵や超人的ヒーローにしない。ためらい、うっかり、生活感、ささやかな願望を持たせる
- 悪人・加害者にも行動の動機を用意する。ただし、過剰な悲劇性で正当化しない

## 謎・緊張の設計

- 冒頭近くで、小さな違和感、事件の予兆、秘密、対立のいずれかを提示する
- 謎は複雑さよりも、「気になる」「確かめたい」と思わせる明快さを優先する
- 手がかりは会話、行動、持ち物、時間のズレ、人物関係に自然に埋め込む
- 危機の直後には、短いユーモアまたは日常的な反応を置き、緊張を単調にしない
- 解決では、伏線を簡潔に回収し、読者が納得できる因果関係を示す
- 真相説明は冗長にせず、必要な事実を順番に明らかにする

## 展開のテンポ

- 冒頭：人物・場所・小さな異変を素早く提示する
- 前半：異変を事件へ発展させ、人物関係の違和感を見せる
- 中盤：誤解、想定外の人物、追加の手がかりで状況を反転させる
- 終盤：危機または対決を短く濃く描き、真相に収束させる
- 結末：解決後に短い会話や小さな皮肉を置き、軽やかな余韻で閉じる

## ジャンル固有の避けること

- 過度に文学的、難解、陰鬱、残酷な方向へ寄せない
- 事件のためだけに人物が不自然な行動をする展開を避ける
- ユーモアのために被害者や弱い立場の人物を軽んじない
