# セッションの依頼文のひな形

コピーして `{{ }}` の部分を書き換えて使う。手順そのもの（正典を読む、字数を測る、記録を更新する、push する）はスキルの既定にあるので、ここには書かない。
書くのは、スキルでは決められない、そのセッションだけの事柄である。不要な行は消してよい。

## 構想のセッション（新作の最初に 1 回）

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ main）を書き込みで接続してください。
接続したら /start-novel で構想を固め、正典を初期化してください。

## いま決まっていること
- ジャンルの候補：{{例：ユーモアのある家族もの／未定}}
- 題材・舞台の候補：{{未定なら「未定」}}
- 主人公の案：{{未定なら「未定」}}
- 規模：{{例：全 12 章・約 9 万字／未定}}
- 公開先と時期：{{例：全章を書き終えてから note で週 1 回}}

## 進め方
- 選択肢は推奨つきで示してください。決まらないものは plot/open_questions.md に残してください。
```

## 章の執筆のセッション

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ {{main または revision/版名}}）を書き込みで接続してください。
接続したら /write-chapter {{章番号}} で第 {{章番号}} 章を書いてください。

## この章だけの前提
- {{例：第 3 章で決めた〇〇の扱いを、この章で初めて本人に知らせる}}

## 申し送りで特に気を付けること
- {{log/continuity.md の「次章への申し送り」のうち、特に落としたくないもの}}

## 書き方の注意
- {{例：目安は 8,000 字。主な視点は A と B}}
- {{例：前の章で指摘された〇〇（動作の順序など）に注意する}}

## 既定と違う後処理
- {{なければこの節を消す。例：閲覧ページの更新は不要}}
```

## 原稿チェックのセッション（閲覧ページの行番号で指摘する）

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ {{ブランチ}}）を書き込みで接続してください。
第 {{章番号}} 章の原稿チェックをします。閲覧ページ（novel.config.json の viewer.url）の行番号で指摘します。

## 進め方
- 指摘ごとに、原因と、修正案を 2〜3 個（推奨つき）で示してください。私が選んでから反映してください。
- 反映したら、log/continuity.md と関係する正典も直し、字数を測り直して plot/outline.md の最終字数を更新し、push してください。
- push のたびに、直した行を --focus にして閲覧ページを公開し直してください。

## 最初の指摘
- {{例：17 行目：〇〇が不自然}}
```

## 推敲と点検のセッション

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ {{ブランチ}}）を書き込みで接続してください。
第 {{章番号}} 章に /polish と /continuity-check をかけてください。
指摘は表で、修正案は推奨つきで示し、私が選んでから反映してください。
```

## note 公開のセッション

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ {{ブランチ}}）を書き込みで接続してください。
第 {{章番号}} 章を note に公開する準備をしてください。

- /note-export {{章番号}} で書き出し、/note-publish {{章番号}} で note に下書き保存してください。
- 予約日時：{{例：novel.config.json の既定どおり／〇月〇日 0:30}}
- 予約・公開の前に、本文・あらすじ・末尾の案内を見せて、私の確認を取ってください。
```

## 構成改稿を始めるセッション

```text
GitHub の {{GitHub のユーザー名}}/{{リポジトリ名}}（ブランチ main）を書き込みで接続してください。
/start-revision {{版名。例：v2}} で構成改稿を始めてください。

## 改稿の動機
- {{例：主人公を A から B に替えたい。中盤の反復を減らしたい}}

## 変えないもの
- {{例：結末、全 12 章という規模}}
```
