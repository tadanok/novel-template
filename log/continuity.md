# 継続性ログ

章を執筆するたび、末尾に追記する。**現行の版の中では、削除・要約しない。**
字数はここには書かない（`plot/outline.md` の「進捗」だけに書く）。
ここに書かれた事実は、後続の章で覆してはならない。
構成改稿で版を改めるときは、`/start-revision` がこのファイルを `log/archive/` へ移し、新しい版の記録を始める。

書式と記入例は `docs/canon-format.md` を参照。各章の項には次を書く。

- **作中日時** — その章がいつの出来事か
- **視点** — 場面ごとの視点人物の並び
- **要約** — 3〜5 行
- **確定した事実** — 固有名詞、数値、場所、人物の来歴など
- **人物の状態変化** — 誰が何を知ったか、関係がどう動いたか
- **設置／回収した伏線** — `plot/foreshadowing.md` の番号と対応させる
- **次章への申し送り** — 未解決のまま持ち越した事項
