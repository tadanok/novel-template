# 私家版の組版

## 用途

公開する前に、限られた相手へ通し読みしてもらうための一冊を作る。
note の下書き共有リンクは 1 記事につき 1 本しか発行できず、全話を通しで読んでもらう用途には向かないため、こちらを使う。

## 手順

### 1. 事前確認

- `chapters/` に `NN_章題.md` 形式のファイルが揃っているか確認する。
- 途中までの章で組んでも構わない。その場合は「第N話まで収録」と明示して渡す。
- `novel.config.json` の `title`・`author`・`notice`・`episode_label` を確認する。`title` が空なら、仮題を入れるかユーザーに確認する。
- `author` が空なら、著者名を入れるかユーザーに尋ねる。空のままでも組めるが、表紙の著者名と EPUB の著者欄が空になる。入れた著者名は `novel.config.json` に書き、commit・push する。

### 2. 組み立てる

```bash
python3 tools/build_book.py
```

外部ライブラリは不要。macOS 標準の python3 で動く。出力は `dist/` に生成される。

- `dist/〈作品名〉.epub` — スマートフォン、Kindle、Apple Books 用
- `dist/〈作品名〉.html` — ブラウザーで開き、印刷から PDF にする用

`dist/` は `.gitignore` に入れてある。生成物はコミットしない。

### 3. 確認する

- スクリプトが出力する章ごとの字数を読み、`plot/outline.md` の目安と比べる。大きく外れている章があればユーザーに報告する。
- `novel.config.json` の `cover_image` の画像があれば、表紙として EPUB に埋め込まれる。無い場合はその旨が表示される。

### 4. 報告し、ファイルを渡す

- 収録した話数と合計字数、生成したファイルのサイズ、表紙の有無を報告する。
- 生成したファイルをユーザーに送る（SendUserFile など）。

## 渡し方（ユーザーへの案内）

- EPUB は iPhone なら AirDrop やメール添付で送れば Apple Books で開ける。Kindle へ送る場合は Amazon の「Send to Kindle」を使う。
- HTML はブラウザーで開いて「プリント」から「PDF として保存」を選べば PDF になる。
- 冒頭に `novel.config.json` の `notice` の注意書きが入る。

## やってはいけないこと

- 本文を書き換えないこと。この工程は組版のみを行う。
- `dist/` をコミットしないこと。
